# DTD Voxel Type Library

This file describes the DTD voxel types generated by
`src/qti_unified/patho.py`. It is written from the current library code, not
from the old repo notes.

The public entry points are:

```python
from qti_unified.patho import CASE_NAMES, available_scenarios, generate_patho_case, generate_patho_suite

case = generate_patho_case(
    scenario="crossing_needles_2",
    case="crossing_needles_2_angle60",
    n_tensors=1500,
)
params = case.params
```

Each generated case is a `PathoCase` with:

- `scenario`: the scenario folder name.
- `case`: the individual case tag.
- `params`: a list of diffusion tensor dictionaries.
- `metadata`: small provenance fields such as scenario, case, tensor count,
  seed, and the swept descriptor value.

## Tensor Parameter Format

Each tensor dictionary stores one diffusion tensor in the same parameter style
used by the old utilities:

- `lambda_1`, `lambda_2`, `lambda_3`: eigenvalues in SI units, `m^2/s`.
- `u1`, `u2`, `u3`: principal direction as a unit vector.
- `d_iso`: isotropic diffusivity, `(lambda_1 + lambda_2 + lambda_3) / 3`.
- `d_delta`: normalized axial anisotropy,
  `(lambda_1 - lambda_23) / (lambda_1 + 2 * lambda_23)` for axisymmetric
  tensors.

Two local constructors are used throughout the scenario library:

- `_axisym_param(lambda_1, lambda_23, direction)` creates a cylindrically
  symmetric tensor where `lambda_2 = lambda_3 = lambda_23`.
- `_sphere_param(d_iso)` creates a perfect isotropic sphere where all three
  eigenvalues equal `d_iso`.

Most large scenarios use `n_tensors=1500` by default. Some scenarios are fixed
toy mixtures and ignore the requested tensor count by design: two crossing
needles, three orthogonal needles, and needle plus sphere.

## Shared Sampling Utilities

The scenario code calls the vendored old utilities instead of replacing their
math:

- `generate_fibers_WM_watson` samples white-matter-like axisymmetric tensors
  with Watson-distributed orientations around a mean direction `mu`. The spread
  is controlled by `odi`. The base eigenvalues are given by `base_d_par` and
  `base_d_perp`. Optional `sigma_iso` and `sigma_delta` add per-tensor
  diffusivity/shape variation.
- `random_unit_vectors` samples directions uniformly on the sphere.
- `truncated_normal` samples bounded normal values for sphere diffusivities.
- `_positive_normal` is a small wrapper used only to reject non-positive
  Gaussian diffusivity samples.

The current code intentionally preserves historical per-scenario random seeds
where the old notebook used them. The public `seed` is kept in the metadata and
in stable case construction, but several generators still use their historical
fixed RNG values so that the generated DTDs match the old workflow.

## Voxel Types

### `crossing_needles_2`

Cases:

```text
crossing_needles_2_angle20, angle28, angle36, angle44, angle52,
angle60, angle68, angle76, angle84, angle90
```

Generation:

- The DTD contains exactly two axisymmetric needle-like tensors.
- Tensor 1 points along `(1, 0, 0)`.
- Tensor 2 points in the xy-plane at the case angle:
  `(cos(angle), sin(angle), 0)`.
- Both tensors use `lambda_1 = 1.7e-9` and
  `lambda_2 = lambda_3 = 0.03e-9`.

What it probes:

- Sensitivity to the angle between two sharp anisotropic components.
- `C_c` and orientation-coherence behavior as the crossing angle opens.

### `crossing_needles_3_xyz`

Cases:

```text
crossing_needles_3_xyz
```

Generation:

- The DTD contains exactly three axisymmetric needle-like tensors.
- Directions are the three Cartesian axes: x, y, and z.
- All tensors use `lambda_1 = 1.7e-9` and
  `lambda_2 = lambda_3 = 0.03e-9`.

What it probes:

- A maximally simple three-way orthogonal crossing.
- High microscopic anisotropy with very dispersed macroscopic orientation.

### `demyelination_progressive_sticks`

Cases:

```text
demyelination_progressive_sticks_end0.03
demyelination_progressive_sticks_end0.10
demyelination_progressive_sticks_end0.15
demyelination_progressive_sticks_end0.20
demyelination_progressive_sticks_end0.25
demyelination_progressive_sticks_end0.30
```

Generation:

- First, `n_tensors` Watson-distributed white-matter tensors are sampled around
  the x-axis.
- Watson parameters:
  - `mu = (1, 0, 0)`
  - `odi = 0.05`
  - `base_d_par = 1.7e-9`
  - `base_d_perp = 0.03e-9`
  - `sigma_iso = 0.03`
  - `sigma_delta = 0.04`
- Directions are flipped when needed so they face the positive x direction.
- The perpendicular diffusivity is then overwritten with a progressive curve:
  `0.03e-9 + (end * 1e-9 - 0.03e-9) * progress**1.35`.
- `lambda_1` stays fixed at `1.7e-9`; `lambda_2` and `lambda_3` follow the
  progressive perpendicular curve.

What it probes:

- A white-matter bundle whose transverse diffusivity increases progressively.
- This is useful for demyelination-like behavior because anisotropy decreases
  as the endpoint `D_perp` increases.

### `fanning_sticks_1500`

Cases:

```text
fanning_sticks_1500_span00, span10, span20, ..., span90
```

Generation:

- The DTD contains `n_tensors` axisymmetric needle-like tensors.
- Directions are deterministic, evenly spaced in the xy-plane from `0` degrees
  to the case span.
- Each tensor uses `lambda_1 = 1.7e-9` and
  `lambda_2 = lambda_3 = 0.03e-9`.

What it probes:

- A controlled fan-shaped orientation distribution.
- Unlike Watson sampling, this is a deterministic angular sweep.

### `frac_gauss_2`

Cases:

```text
Frac_0.00, Frac_0.10, Frac_0.20, ..., Frac_0.90
```

Generation:

- The case value is the isotropic fraction `f_iso`.
- `round(f_iso * n_tensors)` tensors become isotropic spheres.
- The remaining tensors are Watson white-matter tensors around the x-axis.
- White-matter parameters:
  - `mu = (1, 0, 0)`
  - `odi = 0.2`
  - `base_d_par = 1.7e-9`
  - `base_d_perp = 0.03e-9`
  - `sigma_iso = 0.0`
  - `sigma_delta = 0.0`
- Isotropic tensors are perfect spheres with `d_iso = 3.0e-9`.
- The mixture is shuffled after construction.

What it probes:

- Increasing free-water-like isotropic partial volume.
- The anisotropic tissue component is kept constant while the sphere fraction
  grows.

### `iso_bimod_gauss_2`

Cases:

```text
iso_bimod0.80_V0.01
iso_bimod0.80_V0.05
iso_bimod0.80_V0.09
iso_bimod0.80_V0.13
iso_bimod0.80_V0.17
iso_bimod0.80_V0.21
iso_bimod0.80_V0.27
iso_bimod0.80_V0.33
iso_bimod0.80_V0.41
iso_bimod0.80_V0.49
```

Generation:

- The DTD contains only isotropic spheres.
- The target mean is `0.80 um2/ms`.
- The case value is the desired variance in `um4/ms2`.
- A fixed within-mode Gaussian width of `0.05 um2/ms` is used.
- The two mode centers are:
  - `mean - sqrt(max(variance - sigma**2, 0))`
  - `mean + sqrt(max(variance - sigma**2, 0))`
- Half of the tensors are sampled from the lower positive normal mode and the
  rest from the upper positive normal mode.

What it probes:

- Pure isotropic diffusivity heterogeneity with no microscopic anisotropy.
- `C_MD` should increase with isotropic diffusivity variance, while `FA`,
  `uFA`, and `C_c` are boundary cases for perfect spheres.

### `iso_uni_gauss_2`

Cases:

```text
iso_uni0.60, iso_uni0.80, iso_uni1.00, iso_uni1.20, iso_uni1.40,
iso_uni1.60, iso_uni1.85, iso_uni2.10, iso_uni2.35, iso_uni2.60
```

Generation:

- The DTD contains only isotropic spheres.
- The case value is the mean sphere diffusivity in `um2/ms`.
- Each sphere diffusivity is sampled from a positive normal distribution.
- The standard deviation is `10%` of the case mean.

What it probes:

- A sweep of mean isotropic diffusivity with proportional spread.
- No orientation information is present because every tensor is spherical.

### `needle_sphere_2`

Cases:

```text
needle_sphere_2tensors
```

Generation:

- The DTD contains exactly two tensors.
- Tensor 1 is a z-axis needle-like tensor:
  - direction `(0, 0, 1)`
  - `lambda_1 = 1.7e-9`
  - `lambda_2 = lambda_3 = 0.03e-9`
- Tensor 2 is an isotropic sphere with `d_iso = 3.0e-9`.

What it probes:

- A minimal mixed anisotropic plus isotropic voxel.
- Useful as a small smoke-test DTD because it has only two components.

### `o_prog_gauss_2`

Cases:

```text
ODI_0.02, ODI_0.08, ODI_0.14, ODI_0.20, ODI_0.28,
ODI_0.36, ODI_0.46, ODI_0.58, ODI_0.72, ODI_0.90
```

Generation:

- The DTD contains `n_tensors` Watson white-matter tensors around the x-axis.
- The case value is the Watson orientation dispersion index `odi`.
- Parameters:
  - `mu = (1, 0, 0)`
  - `base_d_par = 1.7e-9`
  - `base_d_perp = 0.03e-9`
  - `sigma_iso = 0.0`
  - `sigma_delta = 0.0`

What it probes:

- Pure orientation dispersion progression.
- Tensor shape is fixed; only the orientation distribution changes.

### `packed_crossings_conserved_2`

Cases:

```text
crossing_angle20_frac50_50, crossing_angle28_frac50_50, ...,
crossing_angle90_frac50_50
```

Generation:

- The DTD contains two Watson-distributed bundles.
- Bundle fractions are fixed at approximately `50% / 50%`.
- Bundle 1 is centered on `(1, 0, 0)`.
- Bundle 2 is centered on `(cos(angle), sin(angle), 0)`.
- Both bundles use:
  - `odi = 0.20`
  - `base_d_par = 1.7e-9`
  - `base_d_perp = 0.03e-9`
  - `sigma_iso = 0.05`
  - `sigma_delta = 0.06`
- The combined tensor list is shuffled.

What it probes:

- Crossing angle effects when each branch is itself dispersed rather than a
  single needle.
- The total branch fraction is conserved across the angle sweep.

### `partial_volume_triplet`

Cases:

```text
partial_volume_triplet_fiso0.10
partial_volume_triplet_fiso0.15
partial_volume_triplet_fiso0.20
partial_volume_triplet_fiso0.25
partial_volume_triplet_fiso0.30
partial_volume_triplet_fiso0.35
partial_volume_triplet_fiso0.40
partial_volume_triplet_fiso0.45
partial_volume_triplet_fiso0.50
partial_volume_triplet_fiso0.55
```

Generation:

- The case value is the isotropic fraction `f_iso`.
- The remaining fraction is split into:
  - `70%` stick-like white matter.
  - `30%` zeppelin-like anisotropic tissue.
- Stick component:
  - `mu = (1, 0, 0)`
  - `odi = 0.30`
  - `base_d_par = 1.7e-9`
  - `base_d_perp = 0.03e-9`
  - `sigma_iso = 0.04`
  - `sigma_delta = 0.05`
- Zeppelin-like component:
  - centered at `32` degrees in the xy-plane
  - `odi = 0.30`
  - `base_d_par = 1.45e-9`
  - `base_d_perp = 0.45e-9`
  - `sigma_iso = 0.05`
  - `sigma_delta = 0.06`
- Isotropic tensors are spheres with `d_iso = 3.0e-9`.
- The final tensor list is shuffled.

What it probes:

- A three-compartment partial-volume mixture.
- It changes free-water-like content while preserving a structured
  anisotropic remainder.

### `spheres_2`

Cases:

```text
spheres_csf_1500
```

Generation:

- The DTD contains only isotropic spheres.
- `d_iso` is sampled with a truncated normal distribution:
  - mean `3.00e-9`
  - standard deviation `0.10e-9`
  - lower bound `2.80e-9`
  - upper bound `3.20e-9`

What it probes:

- A CSF-like isotropic voxel with small diffusivity spread.
- Orientation and anisotropy are absent by construction.

### `spheres_sizevar_2`

Cases:

```text
spheres_sizevar_1500_w0.00
spheres_sizevar_1500_w0.20
spheres_sizevar_1500_w0.40
spheres_sizevar_1500_w0.60
spheres_sizevar_1500_w0.80
spheres_sizevar_1500_w1.00
spheres_sizevar_1500_w1.25
spheres_sizevar_1500_w1.50
spheres_sizevar_1500_w1.75
spheres_sizevar_1500_w2.00
```

Generation:

- The DTD contains only isotropic spheres.
- The case value `w` controls a uniform diffusivity width in `um2/ms`.
- A uniform random number `u` in `[0, 1]` is sampled for each tensor.
- For `n_tensors >= 2`, the first two samples are forced to `0` and `1` before
  shuffling so the endpoints are represented.
- Sphere diffusivity is:
  `d_iso_um = 3.00 - w * u`.
- The stored eigenvalues are then `d_iso_um * 1e-9`.

What it probes:

- Increasing isotropic diffusivity spread while keeping all tensors spherical.
- At `w = 0.00`, all tensors are identical perfect spheres, which makes some
  anisotropy ratios mathematically undefined.

### `sticks_2`

Cases:

```text
stick_1500_dperp_0.05
stick_1500_dperp_0.08
stick_1500_dperp_0.11
stick_1500_dperp_0.14
stick_1500_dperp_0.18
stick_1500_dperp_0.22
stick_1500_dperp_0.27
stick_1500_dperp_0.33
stick_1500_dperp_0.40
stick_1500_dperp_0.48
```

Generation:

- The DTD contains `n_tensors` axisymmetric tensors.
- Directions are sampled uniformly on the sphere with `random_unit_vectors`.
- `lambda_1 = 1.7e-9`.
- `lambda_2 = lambda_3 = case_dperp * 1e-9`.

What it probes:

- A sweep from very stick-like tensors to less anisotropic axisymmetric
  tensors.
- The orientation distribution is isotropic, so the voxel can have low
  macroscopic FA while the tensors remain microscopically anisotropic.

## How These DTDs Enter The Full Workflow

The DTD library only creates `PathoCase.params`. The rest of the workflow uses
those parameters as inputs:

1. `generate_patho_case` or `generate_patho_suite` creates the DTD parameters.
2. `qti_unified.qti_math.gt_scalars_from_params` computes and stores GT
   scalars from the DTD.
3. `qti_unified.signals.write_case_outputs` writes DTD JSON, GT JSON, exact
   signal, optional cumulant-expansion signal, and optional SNR realizations.
4. `qti_unified.pipeline.compare_patho_predictions` combines stored GT, MLP
   predictions, and optional covariance-fit results for plotting.

This separation is intentional: DTD generation lives in `patho.py`; signal
synthesis, GT calculation, MLP prediction, covariance-fit loading, and plotting
are separate library steps.
